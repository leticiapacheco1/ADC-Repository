The B-dot controller in this repository implements a magnetic detumbling law used to reduce spacecraft angular velocity by generating a magnetic dipole moment proportional to the time derivative of the local magnetic field in the spacecraft body frame. The implementation is split into two complementary environments: a hardware-in-the-loop embedded controller running on Raspberry Pi, and a high-fidelity orbital simulation implemented in MATLAB and STK.

The purpose of separating these two implementations is to validate both the physical feasibility of magnetorquer actuation and the expected closed-loop detumbling performance under orbital magnetic field conditions.

# Embedded Implementation
The embedded implementation computes the B-dot control law using sequential magnetometer readings acquired from the onboard IMU. The magnetic field derivative is estimated numerically as a finite difference between consecutive time steps. The resulting vector is scaled by a tuned gain and saturated to the magnetorquer dipole limits.

The dipole command is then mapped to an H-bridge driver using a single-axis actuation approximation, where the largest component of the commanded vector is selected and converted into a current-controlled PWM signal.

A key limitation of this implementation is that only one effective actuator axis is driven at a time, which simplifies hardware constraints but introduces coupling between control axes in the physical response.

This file is used to validate real-world actuator behavior, GPIO timing stability, and magnetorquer response under embedded execution constraints.

# STK + MATLAB Simulation 
The MATLAB/STK implementation models full three-axis spacecraft rotational dynamics under the influence of a magnetic torque generated by a B-dot control law. The simulation uses orbital propagation to compute time-varying Earth magnetic field vectors along the spacecraft trajectory, which are then transformed into the body frame using quaternion-based attitude propagation.

The control law computes a continuous magnetic dipole moment proportional to the filtered derivative of the magnetic field, and the resulting torque is computed using the cross product between dipole moment and magnetic field.

Unlike the hardware implementation, the simulation assumes full three-axis actuation and continuous control authority, allowing idealized torque generation without actuator scheduling constraints.

This allows direct observation of detumbling convergence behavior under orbital conditions and provides a baseline for expected performance.
